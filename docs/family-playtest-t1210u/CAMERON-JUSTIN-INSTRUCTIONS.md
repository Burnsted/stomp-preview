# Instructions for Cameron & Justin — family playtest

This is a **family playtest preview**, not a finished app store build. Everything is simulated and stays on your phone’s browser unless you explicitly copy/share Feedback.

## Before you start

1. Use the preview link Ted shares from the draft PR (when available). Do not expect App Store / Play Store.
2. Prefer a current Chrome (Android) or Safari (iPhone).
3. If something looks stuck from an older try: tap **Reset Demo** on Home.

## 5-minute walkthrough

1. **Home** — confirm you see **Explore Demo**, **Feedback**, and **Reset Demo**.
2. Tap **Explore Demo** → open **Create a STOMPER** (or skip and jump ahead).
3. Open **Clips-first Profile** — skim clips, squad, boards.
4. Open **Join sample Trip Drop** — Preview → Join (after a STOMPER / avatar label like Woman 2).
5. Try **Squad + Quick Share** — join North Crew; share stays local.
6. Open **Bag of Tricks** — browse Learn / My Bag.
7. Tap bottom tabs: **Home · Map · Music · Stats · Crew**. Confirm none blank-crash.
8. Optional: **Feedback** → Liked / Confused / Crashed / Wish list → Copy or Share the summary to Ted.

## Character labels

UI uses **Woman / Man / Grom N** only — not invented first names.

## What “Simulated” means

Badges like **Simulated** / **Local only** mean the feature is demo fiction on this phone — not live accounts, payments, or real child/Grom accounts.

## If it crashes

1. Reload the page.
2. Tap **Reset Demo**.
3. Leave Feedback → **Crashed** with what you tapped last.
4. Tell Ted the phone model + browser.

## Arcade

Approved arcade / Terrain Park **release links from main** stay separate. This preview is the snowboard journey shell — don’t treat arcade games as broken if they’re not inside this draft.
