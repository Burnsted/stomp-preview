# Terrain Park game — feature reference pack (pre-build)

Sibling concept to Boulder Dodge: same one-tap downhill DNA, but **park line** progression (jibs → jumps → transitions) instead of boulder/wildlife dodge.

## Feature catalog (design vs Boulder Dodge)

| Feature | Role in park game | vs Boulder Dodge |
|---------|-------------------|------------------|
| Flat / beginner box | Early grind; wide, ride-on | New (BD has snowcat decks only) |
| Straight / down rail | Narrow grind; timing + balance | New |
| Rainbow / S / kinked box | Mid progression jibs | New |
| Tabletop jump | Core air; table + knuckle + landing | BD has tabletops; park emphasizes lip/knuckle scoring |
| Gap jump | Commit air; miss = fall in gap | New pressure beat |
| Hip / corner | 90° landing read | New |
| Step-up / step-down | Elevation change jumps | Partial overlap with BD plateaus |
| Quarterpipe / wallride | Transition air / stall | New |
| Halfpipe / spine (late) | Advanced transition line | New / optional late levels |
| Rollers | Soft early speed bumps | Soft overlap with BD hills |

**Skip for v1:** 50-trick catalogs, open-world Steep, multi-button carve.

**Progression idea:** S features (flat box, small table) → M (rails, rainbow, mid table) → L (gaps, hips, QP) → optional pipe/spine. Score via clean grind length, flip/hold, near-miss lips, combo speed — not boulder dodging.

Sources: NZSIA park manual, Snow-Online park dictionary, WSF glossary, Snowtrex funpark guide, Wikipedia Terrain park.
